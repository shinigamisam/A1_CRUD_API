Task API

A simple RESTful CRUD API built with Node.js and Express.js for managing tasks.

The API supports creating, reading, updating, and deleting tasks. It also includes input validation and interactive API documentation using Swagger UI.

Features
Create tasks
Get all tasks
Get a task by ID
Update a task
Delete a task
Input validation
Swagger API documentation
